# PumpScanBot

Telegram-бот для отслеживания любой активности выбранных Solana-кошельков.

Основная production-схема: на Windows меняется и тестируется только код, затем
он отправляется в GitHub; `.env`, SQLite, ngrok и работающий бот находятся на
Oracle VM. Полный порядок действий описан в
[SERVER_RUNBOOK.md](SERVER_RUNBOOK.md).

Локальный запуск остаётся дополнительной возможностью. Для него используй
[START_HERE.md](START_HERE.md).

После первой настройки запускай бот двойным щелчком по `ЗАПУСТИТЬ БОТА.bat`.
Скрипт сам запускает ngrok, обновляет его ссылку в `.env` и синхронизирует
Helius только тогда, когда публичная ссылка действительно поменялась.

Для круглосуточного запуска на бесплатной Oracle Cloud VM используй
[ORACLE_HOSTING.md](ORACLE_HOSTING.md). Серверная установка не меняет способ
локального запуска на Windows.

Для ежедневной работы через Git, разделения production и test-базы,
первого запуска и последующих обновлений сервера используй
[SERVER_RUNBOOK.md](SERVER_RUNBOOK.md).

Бот не хранит приватные ключи, ничего не покупает и не продает. Он принимает публичные on-chain события от Helius Webhooks и присылает уведомления о swap, переводах SOL/токенов и других действиях. Для pump-покупок и продаж сохраняется подробный формат с фильтром по SOL.

## Что умеет

- добавлять кошельки через Telegram;
- подписывать кошельки понятными именами;
- включать/выключать слежку по каждому кошельку;
- ставить глобальный минимум покупки в SOL;
- ставить отдельный минимум для конкретного кошелька;
- получать уведомление при покупке pump-токена;
- получать уведомление при продаже pump-токена;
- смотреть примерный остаток Helius credits через `/limit`;
- получать Telegram-предупреждение, если Helius credits почти закончились;
- узнавать свой Telegram user id через `/whoami`;
- вручную синхронизировать Helius webhook через `/sync`;
- хранить состояние в SQLite;
- не присылать дубли по одной и той же транзакции.

## Установка, не запуск

Этот шаг только ставит зависимости и готовит `.env`. Сам бот запускается позже через `.\run.ps1`, уже после вставки токенов.

Открой PowerShell:

```powershell
cd "C:\Users\Evgeniy\Desktop\Py\Проекты\pumpscanbot"
.\setup.ps1
```

Открой `.env` и вставь значения:

- `TELEGRAM_BOT_TOKEN` - токен от @BotFather;
- `HELIUS_API_KEY` - API key из Helius dashboard;
- `HELIUS_PROJECT_ID` - project id из Helius, нужен для `/limit`;
- `PUBLIC_WEBHOOK_URL` - публичный HTTPS URL до твоего ПК;
- `HELIUS_AUTH_HEADER` - любая длинная секретная строка.

## Как запустить локально

Helius не может отправлять webhook на `localhost`, поэтому нужен публичный HTTPS-туннель.

Вариант с ngrok:

```powershell
ngrok http 8080
```

Скопируй HTTPS-адрес вида:

```text
https://abc123.ngrok-free.app
```

и вставь его в `.env`:

```env
PUBLIC_WEBHOOK_URL=https://abc123.ngrok-free.app
```

Потом, когда `.env` уже заполнен и ngrok запущен, запусти бота:

```powershell
.\run.ps1
```

В Telegram напиши своему боту `/start`.

После `/start` появится постоянная нижняя клавиатура. Если старое главное меню уехало вверх по чату, нажми кнопку `Меню`.

## Главное меню

В Telegram будут кнопки:

- `Кошельки` - список кошельков;
- `Добавить кошелек` - добавить адрес и подпись;
- `Глобальный минимум` - общий фильтр суммы;
- `Лимит Helius` - остаток credits;
- `Помощь` - краткая инструкция.

Пример добавления:

```text
7xKxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx Alpha sniper
```

Если отправить только адрес, бот сам сделает короткую подпись.

## Как работает webhook

FastAPI поднимает локальный endpoint:

```text
POST /helius/webhook
```

Полный публичный URL будет таким:

```text
https://abc123.ngrok-free.app/helius/webhook
```

Когда ты добавляешь или выключаешь кошелек, бот при `HELIUS_AUTO_SYNC=true` пытается обновить один общий Helius webhook со списком включенных адресов.

Бот присылает два типа событий:

```text
🟢 Покупка pump-токена
🔴 Продажа pump-токена
```

Например, если кошелек подписан как `Красный`, уведомление будет начинаться с этой подписи, чтобы сразу было понятно, кто купил или продал.

## Важные нюансы

- Helius webhook management операции стоят credits, поэтому не стоит каждую минуту массово менять список кошельков.
- Авто-проверка Helius usage по умолчанию идет раз в 6 часов и предупреждает при остатке 10% или меньше.
- Детектор покупки специально консервативный: он ищет входящий SPL-токен на кошелек и расход SOL в той же транзакции, плюс проверяет участие Pump/PumpSwap программ.
- Для первых тестов лучше поставить маленький `DEFAULT_MIN_SOL`, например `0.01`.
- Если ngrok URL сменился, обнови `PUBLIC_WEBHOOK_URL` в `.env` и нажми в боте синхронизацию через изменение кошелька или перезапусти и заново сохрани настройки.
